RAJDEEP MONDAL — PORTFOLIO UPDATE

Files in this package:
- index.html: page content and metadata
- styles.css: responsive layout, typography, light/dark themes
- script.js: theme toggle, mobile menu, current year
- robots.txt and sitemap.xml: configured for https://rjdpm.github.io/

INSTALLATION
1. Make a backup of the current files in your repository.
2. Copy index.html, styles.css, script.js, robots.txt, and sitemap.xml into the ROOT of your rjdpm.github.io repository.
3. Keep your existing logo.png in the same root folder (it is used as the favicon).
4. Commit and push the changes to the main branch.
5. Open https://rjdpm.github.io/ and hard-refresh the browser if the old styling is cached.

CONTENT CHECK

uses the theme button, that choice is remembered in that browser.
